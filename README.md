# AstrBot hzcubing 插件

基于 AstrBot 的 hzcubing 社群交互插件，具备查询、录入等功能

## 命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/gr` | 查询官方项目 GR；支持 `/gr 官方`、`/gr 趣味`、`/gr 整活` | `/gr 趣味` |
| `/gr历史` | 查询某个项目的 GR 打破历程，支持项目名称或 code | `/gr历史 333` |
| `/排行榜` | 查询项目排行榜 | `/排行榜 333 单次` |
| `/lc总榜` | 查询 LastCubeX 项目历史总榜（按平均） | `/lc总榜 333` |
| `/绑定` | 绑定 QQ 与站内昵称 | `/绑定 会枝` |
| `/录入` | 录入个人成绩 | `/录入 333 12.34 15.67` |
| `/创建` | 创建整活项目，默认把项目名同时作为代码和名称提交 | `/创建 三阶镜面` |
| `/个人记录` | 查询个人记录 | `/个人记录` |
| `/个人记录图` | 生成个人记录图片 | `/个人记录图` |
| `/cto` | 生成 CTO 打乱 | `/cto` |
| `/俊改` | 发送俊改图片 | `/俊改` |
| `/赛赛` | 查询魔方赛赛成绩 | `/赛赛 胡泽亮` |

## 更新

- `v1.0.6`
  - 新增 `/lc总榜` 命令，支持查询 LastCubeX 指定项目历史总榜并批量补齐昵称

- `v1.0.5`
  - 新增 `/gr历史` 命令，按项目查询单次与平均 GR 打破历程

- `v1.0.4`
  - `/个人记录图` 改为 Pillow 本地绘制，移除 HTML 截图渲染链和临时图片文件
  - 图片发送改为 `Comp.Image.fromBytes(...)`，降低外部渲染服务和临时文件清理带来的失败概率
  - 新增个人记录图基础渲染测试

- `v1.0.3`
  - 重新整理插件目录结构，移除顶层散落的命令与工具模块
  - 代码改为按 `commands/`、`services/`、`utils/`、`integrations/`、`assets/` 分类
  - 顶层只保留 `main.py` 与文档元数据文件，便于后续维护

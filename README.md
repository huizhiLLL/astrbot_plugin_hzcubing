# AstrBot hzcubing 插件

为 AstrBot 开发的 hzcubing 社群扩展插件，聚焦社群成绩、绑定、录入、排行榜和赛赛查询。

## 命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/gr` | 查询 GR 记录，可附带项目 | `/gr 333` |
| `/绑定` | 绑定 QQ 与站内昵称 | `/绑定 会枝` |
| `/录入` | 录入个人成绩 | `/录入 333 12.34 15.67` |
| `/个人记录` | 查询绑定 QQ 的个人记录 | `/个人记录` |
| `/个人记录图` | 生成个人记录图片 | `/个人记录图` |
| `/排行榜` | 查询项目排行榜 | `/排行榜 333 单次` |
| `/cto` | 生成 CTO 打乱 | `/cto` |
| `/俊改` | 发送俊改图片 | `/俊改` |
| `/赛赛` | 查询魔方赛赛成绩 | `/赛赛 胡泽亮` |

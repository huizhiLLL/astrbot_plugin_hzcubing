# AstrBot hzcubing 插件

基于 AstrBot 的 hzcubing 社群交互插件，具备查询、录入等功能

## 命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/gr` | 查询 GR ，可附带项目 | `/gr 333` |
| `/排行榜` | 查询项目排行榜 | `/排行榜 333 单次` |
| `/绑定` | 绑定 QQ 与站内昵称 | `/绑定 会枝` |
| `/录入` | 录入个人成绩 | `/录入 333 12.34 15.67` |
| `/创建` | 创建整活项目，默认把项目名同时作为代码和名称提交 | `/创建 三阶镜面` |
| `/个人记录` | 查询个人记录 | `/个人记录` |
| `/个人记录图` | 生成个人记录图片 | `/个人记录图` |
| `/cto` | 生成 CTO 打乱 | `/cto` |
| `/俊改` | 发送俊改图片 | `/俊改` |
| `/赛赛` | 查询魔方赛赛成绩 | `/赛赛 胡泽亮` |

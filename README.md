# AstrBot 魔方插件

为 AstrBot 开发的魔方扩展查询插件（配合 WCA 插件使用）

## 命令

| 命令 | 说明 | 示例 |
|------|------|------|
| `/cube帮助` | 显示命令帮助 | `/cube帮助` |
| `/one` | 查询 one 平台成绩 | `/one 李华` |
| `/pr` | 双平台 PR 查询 | `/pr 李华` |
| `/prpk` | 双平台 PR PK | `/prpk 李华1 李华2` |

## 安装

在 AstrBot 插件目录安装：

```bash
cd astrbot/plugins
git clone https://github.com/huizhiLLL/astrbot_plugin_hzcubing.git
```
